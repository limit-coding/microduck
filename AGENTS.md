# Collaboration notes

- This is a single repository containing four imported components. Read the README in the component you change before editing.
- Keep changes focused and explain cross-component dependencies in the pull request.
- Preserve existing license and copyright notices. Do not add a repository-wide license without explicit authorization.
- Do not commit credentials, local environment files, generated caches, or private team reports.
- When importing a newer upstream revision, record its full source commit in `UPSTREAMS.json` and describe any local changes that need reconciliation.
- Do not assume hardware behavior from simulation alone; document the test conditions for physical-device changes.
